Privacidad de solicitudes

Última actualización: 13 de septiembre de 2026.

Qué datos se solicitan

El formulario solicita nombre, teléfono, comuna, el motivo general de atención y si existe indicación médica. No pidas ni ingreses diagnósticos, recetas ni documentos clínicos en este formulario.

Para qué se usan

Los datos se usan solamente para revisar si la solicitud corresponde, coordinar una atención y comunicarse contigo. No se usan para publicidad ni se venden a terceros.

Dónde se guardan

Las solicitudes se registran en GoHighLevel, plataforma usada para organizar contactos y coordinación. El acceso queda limitado a Diego Ulloa para este fin.

Tus derechos

Puedes solicitar acceso, corrección o eliminación de tus datos escribiendo a enfermero.diegoulloa@gmail.com.

Urgencias

Este sitio no atiende urgencias. Ante una emergencia, llama al 131 o acude al servicio de urgencia más cercano.
